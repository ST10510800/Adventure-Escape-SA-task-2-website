# Adventure Escape SA - Website Development (Task 2 / Phase 3)

Welcome to the official repository for **Adventure Escape SA**, a web platform designed for an outdoor adventure and eco-tourism SME in South Africa.

---

## 📌 Project Overview
Adventure Escape SA offers guided outdoor activities across South Africa, including ziplining, rock climbing, hiking, and mountain packages. This project focuses on the initial HTML structure implementation for Task 2 / Phase 3, establishing semantic layouts, interactive form placeholders, and consistent relative navigation across all required pages.
